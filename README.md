## 1. Мета роботи
Розгортання Java-проєкту та базова обробка даних. Створити програму, яка читає дані про обладнання, перевіряє записи та формує звіт. Налаштувати збірку через Maven Wrapper, тести JUnit 5, SpotBugs, виконуваний JAR і перевірку на трьох ОС.

## 2. Постановка задачі
Програма читає `data/input.csv` або файл, заданий через `--input`. Кодування UTF-8. У кожному рядку 5 полів через `;`: `Дата`, `Назва`, `Категорія`, `Кількість`, `Ціна`.
За коректними записами обчислюється:
1. Загальна кількість коректних записів.
2. Загальна вартість усіх одиниць обладнання.
3. Позиція з найвищою вартістю.
4. Найпопулярніша категорія за кількістю одиниць.

## 3. Інфраструктура
